What is UUMA?

UUMA is an experimental research framework that chains several different hashing steps ("phases") into one proof-of-work function. The goal is to study whether mixing different kinds of work changes which hardware does best.

It is not a miner for Bitcoin or any existing coin, and it has not been reviewed by outside cryptographers. Everything below is measured from the project's real test and benchmark output.

How it works

Plain version: the input goes through five different steps, one after another. Each step feeds the next, and the final 32-byte result is what gets checked against the difficulty target. Every step also mixes in the attempt number (the nonce), so each attempt gives a different answer.

What it does not do

  • Not a miner for any existing chain; all real chain backends are not implemented.
  • Stratum V2 and all real chain backends: not implemented; Stratum V1 exists as a protocol layer only. The manager runs only against a local dry-run chain.
  • No external cryptographic review; not production-ready.
  • Not quantum-resistant and no defence against 51% attacks.
