OmniGPT-Web
OmniGPT-Web is a versatile AI-powered assistant that can function across multiple roles, such as a personal assistant, coach, advisor, customer support agent, therapist, mentor, and much more. It leverages the power of OpenAI's models to provide users with real-time interaction across various domains.

This web app is powered by **React** and **Vite**, providing a fast, responsive, and modern user interface.

Live Demo

Check out the live demo of the app:
[OmniGPT Web](https://omnigpt-web-y8qd.vercel.app/)


Features

* **Versatile AI Assistant**: OmniGPT can function as a radio host, news presenter, telemarketer, GPS navigator, financial advisor, mentor, teacher, and much more.
* **Real-time Interaction**: Get quick and responsive answers across a variety of topics.
* **Tailored Assistance**: Each interaction adapts based on user input, helping to find solutions to a wide array of queries.
* **User-friendly UI**: Clean and simple user interface built with React, TailwindCSS, and Vite for optimal performance.
* **Deployable**: Easily deploy your version with Vercel, or run locally for development.


Tech Stack

* **React**: A JavaScript library for building user interfaces.
* **Vite**: A fast build tool for modern web development.
* **TailwindCSS**: A utility-first CSS framework for creating custom designs.
* **OpenAI API**: Backend AI model to provide the main intelligence behind OmniGPT.


Installation

To get started with the project, clone the repository:

```bash
git clone https://github.com/Leonydis138/omnigpt-web.git
cd omnigpt-web
```

Dependencies

Install the required dependencies using **npm**:

```bash
npm install
```

Development

To start the local development server:

```bash
npm run dev
```

This will launch the app at `http://localhost:3000`.

Build

To build the app for production:

```bash
npm run build
```

This will create a `dist/` folder with the optimized production files.


Deployment

This project is easily deployable on [Vercel](https://vercel.com/) or any other hosting platform that supports **Node.js** apps.

For deployment to Vercel:

1. Create a Vercel account if you don't have one.
2. Link your GitHub repository.
3. Vercel will automatically handle the build and deployment process.


Usage

* **Ask anything!** Type in your queries and get responses across different domains (finance, health, technology, etc.).
* **Adjust to your needs**: OmniGPT is designed to handle many roles, and you can experiment by asking different kinds of questions.
