# self-improving-code-analyzer-v12

A self-improving math toolkit.

## Install from TestPyPI

```
pip install --index-url https://test.pypi.org/simple/ self-improving-code-analyzer-v12
```

## Example

```python
from mathlib_core.mathlib import MathLib
ml = MathLib()
print(ml.factorial(5))  # 120
```
